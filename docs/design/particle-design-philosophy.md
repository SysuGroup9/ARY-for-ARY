# ARY 粒子动画视觉哲学

## 方案一：Code Constellation — 代码星图

**视觉风格**：暗蓝虚空中的光点星图。30-50 颗微小粒子（1.5-3px）如散落代码般漂浮，粒子之间在 120px 距离内形成半透明连线。粒子色取自品牌蓝 `#2362FF` 至 `#4F8CFF` 渐变区间，连线的透明度随距离线性衰减。整体如夜空星座，隐喻 AI 代理在数字宇宙中竞速穿行。

**交互逻辑**：鼠标悬停时，光标周围 200px 内的粒子被柔和吸引（加速度 0.003），形成"星云凝聚"效果。鼠标离开后粒子缓慢回归原位。连线仅在粒子距离 ≤120px 时渲染，自然形成局部星群。

**性能考量**：Canvas 2D、50 粒子、requestAnimationFrame。连线 O(n²/2) 在 50 粒子时只需 1225 次距离判断，远低于 16ms 帧预算。粒子位置缓存避免每帧 GC。半透明背景擦除（`fillStyle rgba(250,251,252,0.15)`）产生自然拖尾。

**配色**：粒子 fill `#2362FF` 到 `#4F8CFF` 随机，连线 stroke `rgba(35,98,255,0.12)` 随距离衰减。

## 方案二：Data Drift — 数据漂移

**视觉风格**：半透明几何碎片从底部向上漂移。粒子为随机 3-6px 的方形或六边形，低透明度（0.03-0.08），配以微弱的品牌蓝色调。运动模拟热力学扩散——粒子从底部随机生成，以 0.2-0.5 px/f 速度上浮，同时有微小水平漂移（±0.1px）。粒子在上边界消失后从底部重生。整体如数据在液态介质中上升，暗合 AI 编码代理"浮出水面"的比赛隐喻。

**交互逻辑**：鼠标移动产生局部"湍流"——光标 150px 半径内的粒子被推开（排斥力与距离平方成反比），形成流体动态。点击时在点击位置瞬间生成 8 个方向喷射粒子，生命周期 1.5s 线性衰减。

**性能考量**：Canvas 2D、最多 60 粒子同时活跃。粒子对象池复用避免分配。使用 `globalCompositeOperation: "screen"` 叠加模式产生柔和光晕，无需额外 blur 计算。

**配色**：粒子 `rgba(35,98,255,0.06)` 到 `rgba(79,140,255,0.04)`，点击波纹 `rgba(35,98,255,0.15)`。

## 方案三：Racing Pulse — 竞速脉冲

**视觉风格**：大半径、极低透明度的光环以不同频率脉动。3-5 个光环（半径 200-600px）在页面上缓慢漂移，每个光环由品牌蓝色渐变构成（中心 `rgba(35,98,255,0.04)` → 边缘透明）。光环以 0.1-0.3 Hz 频率缩放脉动，模拟赛道上的心跳节拍。不用 Canvas，纯 CSS radial-gradient + animation 实现，零 JS 开销。

**交互逻辑**：光环位置跟随鼠标，有 0.5s 弹性缓动延迟，产生柔和的追随感。鼠标静止时脉动频率降低 50%，移动时恢复。不消耗主线程。

**性能考量**：纯 CSS 方案，GPU 加速的 `transform` 和 `opacity` 动画。3-5 个伪元素或绝对定位 div，`will-change: transform, opacity` 提示浏览器优化。零帧预算占用，极低电量消耗。

**配色**：光环从品牌蓝 `rgba(35,98,255,0.04)` 渐变至透明。脉动缩放 0.95-1.05 区间，避免过大位移。移动时光环 `opacity` 提升 30%。
