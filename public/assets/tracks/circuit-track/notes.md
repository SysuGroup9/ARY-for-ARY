# circuit-track 环形赛道校准说明

## 底图

SVG 自绘，城市环形赛道。1920×1080，蓝灰冷调配色。

## 校准参数

| 参数 | 值 |
|------|-----|
| 画布 | 1920×1080 |
| 控制点数 | 16（含 4 个圆角过渡区） |
| 方向 | 逆时针 |
| 车道 | 3 条，偏移 -45 / 0 / +45 px |

## 切换方式

修改快照 JSON 中 `trackId` 为 `"circuit-track"`，或 Organizer 生成快照前在 Race 数据中指定 trackId。
