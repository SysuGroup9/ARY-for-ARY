# 赛道资产说明

## 文件清单

| 文件 | 用途 |
|------|------|
| `track.profile.json` | 标准椭圆赛道（oval-standard），默认12 个控制点 |
| `rect.profile.json` | 标准方形赛道（rect-standard），默认12 个控制点 |
| `notes.md` | 本文件，赛道参数与校准说明 |
| `source.prompt.md` | 赛场底图的生成说明 |

底图文件位于 `public/jumbotron底图.jpg`，可由用户提供（实景赛场照片）。

---

## 坐标系说明

所有控制点均在 **1920 × 1080 像素坐标系**下定义，与 Jumbotron SVG viewBox 完全一致。坐标直接写入 `TrackProfile.centerline.points`，无需缩放。

## oval-standard（标准椭圆）

**版本：** v2（2026-06-12 缩放调整）

**控制点：**
```
[1472, 540], [1403, 424], [1216, 339], [960, 308],
[704,  339], [517,  424], [448,  540], [517,  656],
[704,  741], [960,  772], [1216, 741], [1403, 656]
```

**几何参数：**
- 中心：(960, 540)
- 横轴宽：1472 − 448 = **1024 px**
- 纵轴高：772 − 308 = **464 px**
- 左/右边距：各 **448 px**
- 上/下边距：各 **308 px**
- 缩放系数：相对原始控制点按 **0.80×** 缩小，以 (960, 540) 为锚点

**校准说明：**
- 原始控制点（v1）左右各距画面边缘仅 320 px，叠加 laneHalfWidth 75 px 后外侧护栏已触碰到背景底图中的看台区域
- v2 将缩放系数从 1.0 调整为 0.80，使外侧护栏到看台安全边距约 370 px
- Catmull-Rom 样条在当前 12 控制点分布下拟合出的椭圆过渡自然，无尖角

## rect-standard（标准方形）

**版本：** v2（2026-06-12 缩放调整）

**控制点：**
```
[1456, 540], [1456, 364], [1280, 316], [960, 308],
[640,  316], [464,  364], [464,  540], [464,  716],
[640,  764], [960,  772], [1280, 764], [1456, 716]
```

**几何参数：**
- 中心：(960, 540)
- 横轴宽：1456 − 464 = **992 px**
- 纵轴高：772 − 308 = **464 px**
- 左/右边距：各 **464 px**
- 上/下边距：各 **308 px**
- 缩放系数：**0.80×**，与椭圆同步

**校准说明：**
- 直道段由左右各两个共线控制点（如 `[1456,540]`、`[1456,364]`）形成，Catmull-Rom 样条在此处几乎退化为直线段，视觉上呈现长直道效果
- 四角各一对控制点（如 `[1456,364]`、`[1280,316]`）形成自然圆角弯道，无 90° 尖角

## 车道参数

两条赛道共用相同的车道配置：

| 参数 | 值 |
|------|----|
| 车道数 | 8 |
| laneHalfWidth | 75 px（内外护栏各距中心线 75 px） |
| 车道偏移公式 | `offset = -75 + 150/(N+1) × (i+1)`，N=8，i∈[0,7] |
| 偏移范围 | −66 px（最内道）→ +66 px（最外道） |

**车道偏移值：**
`−66, −47, −28, −9, +9, +28, +47, +66`（单位：px，正值偏向赛道外侧）

## 如何使用 Calibrator 生成新赛道

1. 访问 `/jumbotron/calibrator`
2. 上传赛场底图（透明度建议 0.25–0.40）
3. 单击沿赛道中线添加控制点（推荐 12–16 个）
4. 拖拽调整，直到 Catmull-Rom 预览曲线与底图赛道吻合
5. 配置车道数、半宽、方向、起/终点 S 值
6. 点击「马匹预览」Scrubber，验证所有位置马匹分布正常
7. 点击「验证」确认无错误
8. 点击「下载 profile.json」，将文件放入本目录
9. 在 `Jumbotron/adapter.ts` 的 `TRACK_MAP` 中注册新 trackId
